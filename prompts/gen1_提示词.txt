你是一位 MV 导演兼技术美术。请用当前目录下的 skill，为我制作一支
二次元动画风格的音乐 MV。音乐是《world.execute(me);》，BPM 130。

【歌曲叙事结构——必须按此设计分镜】

这首歌的歌词是一条完整的叙事弧线，分为四个阶段：

阶段一：程序初始化（Intro）
- 歌词意象："接上电源""绝缘护体""摆好棋子""生成对象""输入参数"
  "数据初始化""模拟程序"。
- 视觉方向：CRT 终端从黑屏到逐行亮起，代码滚动出现，模拟
  "程序正在被创建"的过程。
- 关键触发点："world.execute(me);"出现时，整个终端画面应有
  一次明显的"执行"脉冲。

阶段二：数学隐喻的爱情（主歌）
- 歌词意象："如果我是一组点→次元""如果我是一个圆→圆周"
  "如果我是一条正弦波→切线""如果我趋于无穷→极限"。
- 视觉方向：这是 MV 最核心的视觉段落。每一句歌词对应一种
  数学形态在 CRT 屏幕上的可视化。
- 关键映射（必须逐句对应）：
  "点"→"次元"：CRT 屏幕上散点聚合，维度扩展。
  "圆"→"圆周"：CRT 屏幕上画圆，圆周发光。
  "正弦波"→"切线"：正弦波在屏幕上振荡，切线随波移动。
  "趋于无穷"→"极限"：曲线趋近一条虚线，虚线闪烁。

阶段三：电流与模拟程序的陷阱（副歌）
- 歌词意象："切换电流从交流到直流""头晕目眩""穿越时空"
  "成为一体""被困在模拟程序中"。
- 视觉方向：CRT 屏幕出现信号干扰、色差加剧、画面短暂扭曲。
  "被困"出现时，画面出现"程序卡死"的冻结感。

阶段四：爱的方程式（Bridge 与结尾）
- 歌词意象："我学会了如何正确去爱""爱的代数表达式"
  "虽然你自由了，但我依然被困在爱之中"。
- 视觉方向：CRT 屏幕上的数学公式从冰冷变得"有温度"——
  荧光绿中混入一丝暖色。最后的"被困在爱之中"，屏幕定格在
  一个循环执行的代码片段上，暗示无限循环。

【视觉核心设定】
- 二次元动画风格，角色元素可从 ds肥鱼三视图.jpg 提取。
- CRT 老电视/显像管终端为核心视觉元素。
- 屏幕上显示：绿色荧光代码（world.execute(me); 的 Java 代码）、
  歌词文本、数学函数图。
- 色调：暗色背景 + 荧光绿/青色辉光 + 轻微 RGB 色差和扫描线。
- 节奏：画面切换和代码滚动踩在 BPM 130 的节拍上。

【歌词展示规范——必须作为 CRT 界面元素处理】

歌词不应做成传统 MV 下方居中字幕，而应做成 CRT 终端"输出"的内容：

1. 出现方式：模仿终端命令行输出。每句歌词作为一行"终端日志"
   从屏幕下方逐行向上滚动出现，或打字机效果逐字打出。
2. 样式：等宽字体，荧光绿/青色，与代码行同字号，行末尾带
   持续闪烁的方块光标。
3. 高亮：当前正在演唱的那一行亮度高于上方已滚过的行，形成
   "当前执行行"的焦点。副歌关键句出现时整行短暂反色/闪烁一次。
4. 数学意象歌词（点/圆/正弦波/极限）：歌词出现时，CRT 屏幕
   同步在旁边绘制对应数学图形——歌词在"说"，图形在"演示"，
   两者在同一帧画面里分区域共存。
5. 位置：歌词行占据 CRT 屏幕左侧或下方区域，右侧留给数学
   图形动画或角色元素。
6. 时间轴：歌词行的出现与消退踩在 BPM 130 的节拍上。每句歌词
   "输出"的瞬间对齐该句人声的起始帧。

【执行流程】
按以下步骤工作，每步先输出计划再执行：

1. 导演与分镜：用 creative-music-video-director + storyboard-director，
   按上述四阶段拆解成带时间码的分镜脚本，标注每句歌词与画面的对应。
2. Prompt 翻译：用 video-prompt-architect 把分镜翻译成可执行 prompt。
3. 素材生成：
   - CRT 界面与歌词：用 hyperframes-workflow 写 HTML/Canvas 动画。
   - 函数图：用 manim-skills 生成正弦波、坐标轴等数学动画。
   - 角色元素：用 image-to-css-art 或 any2video，参考
     ds肥鱼三视图.jpg。
4. 节拍同步与合成：用 motion-video-skill 对齐 BPM 130，
   让画面切换、歌词行输出、函数波动都踩在节拍上，输出 1080p 视频。

每步完成后汇报产出文件与下一步计划。若某 skill 的输入格式不确定，
先读该目录下的 README 或 skill 定义。
